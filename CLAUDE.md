# CLAUDE.md — Quorum Build Context

You are implementing a one-day hackathon project in Jac.

## Before making changes

1. Read `AGENTS.md`.
2. Read `PACKAGE_INDEX.md`.
3. Read all documents in `docs/`.
4. Inspect the current tree.
5. Run the current compile or test command.
6. Summarize the exact milestone and files you propose to change.

## Product thesis

A community objection matters only when it is countable, on the record, and aimed at whoever actually decides.

Quorum compares:

- impact zone,
- mobilization zone,
- decision zone,
- paid-media target zone.

## Graph model

One Jac workspace contains seven explicit semantic layers:

1. issue and signal,
2. narrative and evidence,
3. community and stakeholder,
4. institution and decision,
5. law and procedure,
6. precedent and action,
7. campaign and activation.

Do not flatten these layers and do not split them into separate databases.

## Implementation priorities

1. Persistent anchors and curated backbone.
2. Portsmouth Square end-to-end fixture flow.
3. Impact walker and decision walker.
4. Divergence check.
5. Evidence and precedent matching.
6. Exactly three recourse paths.
7. Campaign dry-run.
8. Thin UI.
9. DataSF live/cache-first.
10. Great Highway second case.

## Non-negotiable boundaries

- No GDELT in MVP.
- No generated procedural facts.
- No live ad spending.
- No claim that a legal standard is satisfied.
- No inference that a stakeholder supports the issue.
- No secrets in source.
- No unannounced architecture changes.

## Working style

Prefer one small compiling patch over a large speculative rewrite. When Jac syntax fails, consult the installed compiler and current official documentation. Preserve the Jac-native graph and walker design.
